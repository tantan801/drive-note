
# 第42章 新字符设备驱动实验

---

## 老接口 vs 新接口

### 老接口：`register_chrdev` / `unregister_chrdev` 缺点

1. 需要手动确定空闲主设备号，容易冲突
2. 一次性占用该主设备号下全部 2^20 个次设备号，严重浪费次设备号资源
3. 驱动加载完成，不会自动生成 `/dev` 设备节点，需要手动 `mknod`

### 新字符设备

内核推荐 API，可以动态申请设备号、按需申请若干个次设备号，驱动加载可自动创建设备节点。

## 42.1.1 分配和释放设备号

### 两个申请设备号函数

#### 1）静态指定设备号（已知主、次设备号）

```c
int register_chrdev_region(dev_t from, unsigned count, const char *name);
```

| 参数      | 说明                                                      |
| --------- | --------------------------------------------------------- |
| `from`  | 使用`MKDEV(major, minor)` 组合出来完整 `dev_t` 设备号 |
| `count` | 申请连续次设备号的数量；一般填**1**                 |
| `name`  | 设备名称                                                  |

#### 2）动态分配设备号（推荐，内核自动分配空闲设备号）

```c
int alloc_chrdev_region(dev_t *dev, unsigned baseminor, unsigned count, const char *name);
```

| 参数          | 说明                                                  |
| ------------- | ----------------------------------------------------- |
| `dev`       | **输出参数**，保存分配成功后的 `dev_t` 设备号 |
| `baseminor` | 次设备号起始编号，一般填**0**                   |
| `count`     | 申请次设备号数量                                      |
| `name`      | 设备名字                                              |

#### 获取主/次设备号宏

```c
MAJOR(devid);              // 从 dev_t 提取主设备号
MINOR(devid);              // 从 dev_t 提取次设备号
MKDEV(major, minor);       // 主、次设备号合成 dev_t
```

#### 3）释放设备号（两种申请方式统一用这个）

```c
void unregister_chrdev_region(dev_t from, unsigned count);
```

### 设备号分配示例代码

```c
int major;          /* 主设备号 */
int minor;          /* 次设备号 */
dev_t devid;        /* 完整设备号 */

if (major) {
    /* 已经定义好主设备号，静态注册 */
    devid = MKDEV(major, 0);            /* 次设备号一般用 0 */
    register_chrdev_region(devid, 1, "test");
} else {
    /* major=0，动态向内核申请空闲设备号 */
    alloc_chrdev_region(&devid, 0, 1, "test");
    major = MAJOR(devid);               /* 提取分配出来的主设备号 */
    minor = MINOR(devid);               /* 提取分配出来的次设备号 */
}
```

**释放设备号**：

```c
unregister_chrdev_region(devid, 1);
```

## 42.1.2 新字符设备注册方法

### 1）`cdev` 结构体

**头文件**：`include/linux/cdev.h`

```c
struct cdev {
    struct kobject kobj;
    struct module *owner;
    const struct file_operations *ops;
    struct list_head list;
    dev_t dev;
    unsigned int count;
};
```

| 成员      | 含义                                 |
| --------- | ------------------------------------ |
| `owner` | 所属模块，一般填`THIS_MODULE`      |
| `ops`   | 指向`file_operations` 操作函数集合 |
| `dev`   | `dev_t` 类型，字符设备完整设备号   |
| `count` | 此 cdev 管理的次设备号数量           |

定义一个字符设备变量：

```c
struct cdev testcdev;
```

### 2）`cdev_init()` — 初始化 cdev 结构体

```c
void cdev_init(struct cdev *cdev, const struct file_operations *fops);
```

| 参数     | 说明                                 |
| -------- | ------------------------------------ |
| `cdev` | 待初始化的`struct cdev` 变量指针   |
| `fops` | `file_operations` 操作函数集合指针 |

```c
struct cdev testcdev;

static struct file_operations test_fops = {
    .owner = THIS_MODULE,
    /* 填充 open/read/write/release 等回调 */
};

testcdev.owner = THIS_MODULE;
cdev_init(&testcdev, &test_fops);       /* 初始化 cdev */
```

> `cdev_init` 只是做结构体内部初始化，**并没有把设备注册进内核**，需要后续调用 `cdev_add`。

### 3）`cdev_add()` — 将 cdev 设备添加进内核

```c
int cdev_add(struct cdev *p, dev_t dev, unsigned count);
```

| 参数      | 说明                                          |
| --------- | --------------------------------------------- |
| `p`     | cdev 结构体指针                               |
| `dev`   | 已经申请好的完整`dev_t` 设备号              |
| `count` | 该 cdev 对应的次设备号数量，一般填**1** |

```c
cdev_init(&testcdev, &test_fops);
cdev_add(&testcdev, devid, 1);          /* 向内核添加字符设备 */
```

执行完 `cdev_add`，字符设备正式对内核可用。

### 4）`cdev_del()` — 卸载驱动，从内核删除 cdev

```c
void cdev_del(struct cdev *p);
```

| 参数  | 说明                     |
| ----- | ------------------------ |
| `p` | 要删除的 cdev 结构体指针 |

```c
cdev_del(&testcdev);
```

---

### 新旧接口等价对比

| 老式接口                               | 等价的新接口组合                                                                                                                      |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `register_chrdev(major, name, fops)` | ①`alloc_chrdev_region()` / `register_chrdev_region()` 申请设备号② `cdev_init()` 初始化 cdev③ `cdev_add()` 添加 cdev 到内核 |
| `unregister_chrdev(major, name)`     | ①`cdev_del()` 删除 cdev② `unregister_chrdev_region()` 释放设备号                                                                |

## 42.2 自动创建设备节点

| 方式             | 说明                                                                                                                                                            |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **旧方式** | 加载 ko 后手动执行`mknod /dev/xxx c 主设备号 次设备号` 创建设备节点                                                                                           |
| **新方式** | 配合`mdev`/`udev`，驱动内部调用 `class_create`、`device_create`，`modprobe`/`insmod` 加载模块自动生成 `/dev/xxx` 节点；`rmmod` 卸载自动删除节点 |

---

## 42.2.1 mdev 机制

1. **`udev`**：Linux 用户态程序，监听内核热插拔事件，自动创建/删除 `/dev` 下设备文件
2. **嵌入式 busybox** 根文件系统提供 udev 简化版本：**`mdev`**
3. 开启 mdev 热插拔，`/etc/init.d/rcS` 脚本中执行：

```bash
echo /sbin/mdev > /proc/sys/kernel/hotplug
```

> ⚠️ 如果根文件系统没有开启 mdev，就算驱动写了 `class_create`、`device_create`，也不会自动生成 `/dev` 下节点。

## 42.2.2 class 类创建与删除

**头文件**：`include/linux/device.h`

### `class_create` — 创建类（宏）

```c
#define class_create(owner, name)       \
({                                      \
    static struct lock_class_key __key; \
    __class_create(owner, name, &__key);\
})
```

| 参数      | 说明                            |
| --------- | ------------------------------- |
| `owner` | 模块所属，一般填`THIS_MODULE` |
| `name`  | 类的名字                        |

**返回值**：`struct class *` 类指针

### `class_destroy` — 删除类（卸载驱动用）

```c
void class_destroy(struct class *cls);
```

| 参数    | 说明                          |
| ------- | ----------------------------- |
| `cls` | `class_create` 返回的类指针 |

---

## 42.2.3 device_create

`device_create —`创建设备(创建驱动)

```c
struct device *device_create(struct class *class,
                             struct device *parent,
                             dev_t devt,
                             void *drvdata,
                             const char *fmt, ...);
```

| 参数        | 含义                                       |
| ----------- | ------------------------------------------ |
| `class`   | 所属 class 类指针                          |
| `parent`  | 父设备，嵌入式一般填**`NULL`**     |
| `devt`    | 完整`dev_t` 设备号                       |
| `drvdata` | 传给设备的私有数据，一般**`NULL`** |
| `fmt`     | 设备文件名，会生成`/dev/fmt`             |

**返回**：`struct device *` 设备指针

`device_destroy` — 删除设备（卸载驱动）

```c
void device_destroy(struct class *class, dev_t devt);
```

| 参数      | 说明   |
| --------- | ------ |
| `class` | 类指针 |
| `devt`  | 设备号 |

完整示例

```c
struct class *class;        /* 类 */
struct device *device;      /* 设备 */
dev_t devid;                /* 设备号 */

/* 驱动入口函数 insmod 执行 */
static int __init led_init(void)
{
    /* 1. 申请设备号、cdev_init、cdev_add 省略 */

    /* 创建类 */
    class = class_create(THIS_MODULE, "xxx");
    /* 在类下面创建设备，自动触发 mdev，生成 /dev/xxx */
    device = device_create(class, NULL, devid, NULL, "xxx");
    return 0;
}

/* 驱动出口函数 rmmod 执行 */
static void __exit led_exit(void)
{
    /* 先删除设备，再删除类，顺序不能颠倒 */
    device_destroy(class, devid);
    class_destroy(class);
}

module_init(led_init);
module_exit(led_exit);
```

> ⚠️ 卸载顺序：先 `device_destroy`，后 `class_destroy`，**不能颠倒**。

## 42.3 设置文件私有数据

不推荐把设备各个属性定义成一堆全局零散变量；应把设备全部属性封装成一个**自定义设备结构体**。

在 `open` 回调中把结构体指针赋值给 `filp->private_data`；后续 `read`/`write`/`release` 回调通过 `filp->private_data` 拿到整个设备信息。

```c
/* 自定义设备结构体，保存该设备全部资源 */
struct test_dev {
    dev_t devid;            /* 设备号 */
    struct cdev cdev;       /* cdev */
    struct class *class;    /* 类 */
    struct device *device;  /* 设备 */
    int major;              /* 主设备号 */
    int minor;              /* 次设备号 */
};

struct test_dev testdev;

/* open 回调函数 */
static int test_open(struct inode *inode, struct file *filp)
{
    /* 将自定义设备结构体赋值给 private_data */
    filp->private_data = &testdev;
    return 0;
}
```

后续 `read` / `write` / `release` 中：

```c
static ssize_t test_read(struct file *filp, char __user *buf, size_t cnt, loff_t *offt)
{
    struct test_dev *dev = filp->private_data;
    /* 使用 dev->devid dev->cdev dev->class 等成员 */
    return 0;
}
```

## 42.5.1 LED 灯驱动程序编写

> **例程文件夹**：`3_newchrled`
>
> 使用新字符设备 API：`alloc_chrdev_region`、`cdev_init`、`cdev_add`、`class_create`、`device_create`
>
> 自动生成 `/dev/newchrled` 设备节点，不需要手动 `mknod`
>
> **硬件**：GPIO1_IO03，低电平点亮 LED

### 完整驱动代码

```c
#include <linux/types.h>
#include <linux/kernel.h>
#include <linux/delay.h>
#include <linux/ide.h>
#include <linux/init.h>
#include <linux/module.h>
#include <linux/errno.h>
#include <linux/gpio.h>
#include <asm/mach/map.h>
#include <asm/uaccess.h>
#include <asm/io.h>
#include <linux/cdev.h>
#include <linux/device.h>

#define NEWCHRLED_CNT   1               /* 设备号个数 */
#define NEWCHRLED_NAME  "newchrled"     /* 设备名字 */
#define LEDOFF          0               /* 关灯 */
#define LEDON           1               /* 开灯 */

/* 寄存器物理地址 */
#define CCM_CCGR1_BASE              (0X020C406C)
#define SW_MUX_GPIO1_IO03_BASE      (0X020E0068)
#define SW_PAD_GPIO1_IO03_BASE      (0X020E02F4)
#define GPIO1_DR_BASE               (0X0209C000)
#define GPIO1_GDIR_BASE             (0X0209C004)

/* 映射后的寄存器虚拟地址指针 */
static void __iomem *IMX6U_CCM_CCGR1;
static void __iomem *SW_MUX_GPIO1_IO03;
static void __iomem *SW_PAD_GPIO1_IO03;
static void __iomem *GPIO1_DR;
static void __iomem *GPIO1_GDIR;

/* newchrled 设备结构体：封装本设备全部资源 */
struct newchrled_dev {
    dev_t devid;            /* 设备号    */
    struct cdev cdev;       /* cdev      */
    struct class *class;    /* 类        */
    struct device *device;  /* 设备      */
    int major;              /* 主设备号  */
    int minor;              /* 次设备号  */
};

struct newchrled_dev newchrled;     /* led 设备全局实例 */

/*
 * @description : LED 打开/关闭
 * @param - sta  : LEDON(1) 打开 LED，LEDOFF(0) 关闭 LED
 * @return       : 无
 */
void led_switch(u8 sta)
{
    u32 val = 0;
    if (sta == LEDON) {
        val = readl(GPIO1_DR);
        val &= ~(1 << 3);           /* bit3 清零，输出低电平点亮 LED */
        writel(val, GPIO1_DR);
    } else if (sta == LEDOFF) {
        val = readl(GPIO1_DR);
        val |= (1 << 3);            /* bit3 置 1，输出高电平熄灭 LED */
        writel(val, GPIO1_DR);
    }
}

/*
 * @description : 打开设备
 * @param - inode: 传递给驱动的 inode
 * @param - filp : 设备文件，设置 private_data 指向设备结构体
 * @return       : 0 成功；其他 失败
 */
static int led_open(struct inode *inode, struct file *filp)
{
    filp->private_data = &newchrled;    /* 设置私有数据 */
    return 0;
}

/*
 * @description : 从设备读取数据，本实验空实现
 */
static ssize_t led_read(struct file *filp, char __user *buf, size_t cnt, loff_t *offt)
{
    return 0;
}

/*
 * @description : 向设备写数据，应用 write 触发此函数
 */
static ssize_t led_write(struct file *filp, const char __user *buf, size_t cnt, loff_t *offt)
{
    int retvalue;
    unsigned char databuf[1];
    unsigned char ledstat;

    retvalue = copy_from_user(databuf, buf, cnt);
    if (retvalue < 0) {
        printk("kernel write failed!\r\n");
        return -EFAULT;
    }

    ledstat = databuf[0];               /* 获取状态值 */

    if (ledstat == LEDON) {
        led_switch(LEDON);              /* 打开 LED 灯 */
    } else if (ledstat == LEDOFF) {
        led_switch(LEDOFF);             /* 关闭 LED 灯 */
    }
    return 0;
}

/*
 * @description : 关闭/释放设备
 */
static int led_release(struct inode *inode, struct file *filp)
{
    return 0;
}

/* 设备操作函数集合 */
static struct file_operations newchrled_fops = {
    .owner   = THIS_MODULE,
    .open    = led_open,
    .read    = led_read,
    .write   = led_write,
    .release = led_release,
};

/*
 * @description : 驱动入口函数，insmod 执行
 * @param       : 无
 * @return      : 无
 */
static int __init led_init(void)
{
    u32 val = 0;

    /* 1、寄存器地址映射 */
    IMX6U_CCM_CCGR1   = ioremap(CCM_CCGR1_BASE, 4);
    SW_MUX_GPIO1_IO03 = ioremap(SW_MUX_GPIO1_IO03_BASE, 4);
    SW_PAD_GPIO1_IO03 = ioremap(SW_PAD_GPIO1_IO03_BASE, 4);
    GPIO1_DR          = ioremap(GPIO1_DR_BASE, 4);
    GPIO1_GDIR        = ioremap(GPIO1_GDIR_BASE, 4);

    /* 2、使能 GPIO1 时钟 */
    val = readl(IMX6U_CCM_CCGR1);
    val &= ~(3 << 26);                  /* 清除以前的设置 */
    val |= (3 << 26);                   /* 设置新值 */
    writel(val, IMX6U_CCM_CCGR1);

    /* 3、设置 GPIO1_IO03 的复用功能，设置 IO 电气属性 */
    writel(5, SW_MUX_GPIO1_IO03);
    writel(0x10B0, SW_PAD_GPIO1_IO03);

    /* 4、设置 GPIO1_IO03 为输出功能 */
    val = readl(GPIO1_GDIR);
    val &= ~(1 << 3);
    val |= (1 << 3);
    writel(val, GPIO1_GDIR);

    /* 5、默认关闭 LED */
    val = readl(GPIO1_DR);
    val |= (1 << 3);
    writel(val, GPIO1_DR);

    /* -------- 新字符设备核心流程 ---------- */
    /* 1、申请设备号，优先动态分配 */
    if (newchrled.major) {              /* 定义了主设备号，静态分配 */
        newchrled.devid = MKDEV(newchrled.major, 0);
        register_chrdev_region(newchrled.devid, NEWCHRLED_CNT, NEWCHRLED_NAME);
    } else {                            /* major=0，动态申请 */
        alloc_chrdev_region(&newchrled.devid, 0, NEWCHRLED_CNT, NEWCHRLED_NAME);
        newchrled.major = MAJOR(newchrled.devid);
        newchrled.minor = MINOR(newchrled.devid);
    }
    printk("newcheled major=%d,minor=%d\r\n", newchrled.major, newchrled.minor);

    /* 2、初始化 cdev */
    newchrled.cdev.owner = THIS_MODULE;
    cdev_init(&newchrled.cdev, &newchrled_fops);

    /* 3、添加 cdev 到内核 */
    cdev_add(&newchrled.cdev, newchrled.devid, NEWCHRLED_CNT);

    /* 4、创建类 */
    newchrled.class = class_create(THIS_MODULE, NEWCHRLED_NAME);
    if (IS_ERR(newchrled.class)) {
        return PTR_ERR(newchrled.class);
    }

    /* 5、创建设备，触发 mdev 自动生成 /dev/newchrled */
    newchrled.device = device_create(newchrled.class, NULL, newchrled.devid, NULL, NEWCHRLED_NAME);
    if (IS_ERR(newchrled.device)) {
        return PTR_ERR(newchrled.device);
    }

    return 0;
}

/*
 * @description : 驱动出口函数，rmmod 执行
 * @param       : 无
 * @return      : 无
 */
static void __exit led_exit(void)
{
    /* 取消 ioremap 地址映射 */
    iounmap(IMX6U_CCM_CCGR1);
    iounmap(SW_MUX_GPIO1_IO03);
    iounmap(SW_PAD_GPIO1_IO03);
    iounmap(GPIO1_DR);
    iounmap(GPIO1_GDIR);

    /* 注销字符设备，注意执行顺序 */
    cdev_del(&newchrled.cdev);                                      /* 删除 cdev */
    unregister_chrdev_region(newchrled.devid, NEWCHRLED_CNT);       /* 释放设备号 */

    device_destroy(newchrled.class, newchrled.devid);               /* 删除设备 */
    class_destroy(newchrled.class);                                 /* 删除类 */
}

module_init(led_init);
module_exit(led_exit);

MODULE_LICENSE("GPL");
MODULE_AUTHOR("zuozhongkai");
```

---

### 代码重点解析

#### 1. 自定义设备结构体

`struct newchrled_dev` 把设备号、cdev、class、device、主/次设备号全部封装；全局实例 `newchrled`。

`led_open` 中将 `filp->private_data = &newchrled`，后续回调函数可以拿到设备资源。

#### 2. `led_init()` 入口完整执行顺序 ⭐（考试大题重点）

| 步骤 | 操作                                                                                         |
| :--: | -------------------------------------------------------------------------------------------- |
|  ①  | `ioremap` 寄存器物理地址映射虚拟 IO 地址                                                   |
|  ②  | 硬件初始化：开启 GPIO1 时钟 → IO 复用配置 → PAD 电气属性 → 设置 GPIO 输出 → 默认熄灭 LED |
|  ③  | `alloc_chrdev_region()` 动态申请设备号                                                     |
|  ④  | `cdev_init()` 初始化 cdev，绑定 `file_operations`                                        |
|  ⑤  | `cdev_add()` 将 cdev 添加进内核                                                            |
|  ⑥  | `class_create()` 创建类                                                                    |
|  ⑦  | `device_create()` 创建设备，mdev 自动生成 `/dev/newchrled` 节点                          |

> `IS_ERR()`、`PTR_ERR()`：判断 class/device 指针是否为错误指针，获取错误码。

#### 3. `led_exit()` 出口卸载顺序 ⚠️（顺序不能颠倒！）

| 步骤 | 操作                                      |
| :--: | ----------------------------------------- |
|  ①  | `iounmap()` 释放 IO 地址映射            |
|  ②  | `cdev_del()` 删除 cdev                  |
|  ③  | `unregister_chrdev_region()` 释放设备号 |
|  ④  | `device_destroy()` 删除设备             |
|  ⑤  | `class_destroy()` 删除类                |

```makefile
kernel_modules:
	$(MAKE) -C $(KERNELDIR) M=$(CURRENT_PATH) modules

clean:
	$(MAKE) -C $(KERNELDIR) M=$(CURRENT_PATH) clean
```

### 编译驱动

```bash
make
```

编译成功以后就会生成一个名为 **`newchrled.ko`** 的驱动模块文件。

### 开发板操作

```bash
# 把 newchrled.ko、ledApp 拷贝到开发板
cp newchrled.ko ledApp /lib/modules/4.1.15/

cd /lib/modules/4.1.15
depmod                          # 生成模块依赖文件
modprobe newchrled.ko           # 加载驱动，自动生成 /dev/newchrled
ls /dev/newchrled -l            # 查看自动生成的设备节点

./ledApp /dev/newchrled 1       # 开灯
./ledApp /dev/newchrled 0       # 关灯

rmmod newchrled.ko              # 卸载驱动，/dev/newchrled 自动消失
```

### 新旧接口完整对比总结

| 对比项                 | 老式接口                                     | 新式接口                                             |
| ---------------------- | -------------------------------------------- | ---------------------------------------------------- |
| **申请设备号**   | `register_chrdev()` 一次性占用全部次设备号 | `alloc_chrdev_region()` 按需申请                   |
| **注册设备**     | `register_chrdev()` 一步完成               | `cdev_init()` + `cdev_add()` 分步                |
| **注销设备**     | `unregister_chrdev()` 一步完成             | `cdev_del()` + `unregister_chrdev_region()` 分步 |
| **设备节点**     | 手动`mknod` 创建                           | `class_create()` + `device_create()` 自动生成    |
| **设备信息管理** | 全局散变量                                   | 封装成自定义结构体 +`private_data`                 |
